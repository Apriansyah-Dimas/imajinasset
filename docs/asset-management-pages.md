# Ikhtisar Halaman, Fitur, & Detail Desain Sistem Asset Management

- **Login (`src/app/login/page.tsx`)** – Layout center card dengan shadow lembut, CTA ungu (#6365b9), input rounded 22px, focus ring ungu; copy singkat untuk akses admin; error alert merah; auto-redirect ke dashboard jika sudah login.
- **Dashboard (`src/app/dashboard/page.tsx`, `src/components/dashboard.tsx`)** – Header dengan ikon Package dalam tile biru; dua KPI cards (total assets, cost) dengan warna biru/hijau; tiga pie charts (dept/site/category) memakai Recharts + custom legend dua kolom; loading skeleton abu-abu; fallback error state; format Rupiah dan thousand separator.
- **Asset Registry (`src/app/assets/page.tsx`)** – Hero teks uppercase “Asset Registry”; action bar dengan tombol Add/Import/Settings (role-based), Export CSV. Pencarian debounce, filter chip status/kategori/site/dept, sort tiles, badge status dengan warna per kondisi, infinite scroll 50/baris dengan sentinel. Tabel desktop + kartu mobile; detail modal; add-asset/import modal; edit dropdowns modal; export downloader; scroll-to-top FAB. Empty state ilustratif, loading skeleton tabel & kartu.
- **Add Asset (`src/app/assets/add/page.tsx`)** – Layout 3 blok (Basic/Classification/Additional) bergaya panel putih + header hitam; input ber-border abu; select kategori/site/dept; status select; validasi wajib dan pesan merah; CTA Save biru, Cancel abu; tombol back ke assets.
- **Bulk Upload (`src/app/assets/bulk/page.tsx`)** – Header back; panel instruksi bertahap; unduh template (`/api/assets/template`) dengan ikon spreadsheet; dropzone drag & drop dengan state highlight; tampilkan file terpilih + aksi remove; upload CSV ke `/api/assets/bulk` dengan spinner; hasil sukses/gagal dengan alert berwarna; daftar field wajib/opsional.
- **Check Out (`src/app/check-out/page.tsx`)** – Flow dua tahap: verifikasi aset via nomor (search button) lalu modal detail read-only, lanjut ke form checkout. Form: checkout date, assign to (PIC select), due date, department, notes, signature pad; button Processing state. Cegah checkout jika ada outstanding. History list dengan filter tanggal (popover), kartu historis dengan status badge, detail collapsible. Persist last asset state di localStorage. Layout kartu putih, badge warna, dialog Next/Cancel.
- **Check In (`src/app/check-in/page.tsx`)** – Verifikasi nomor aset (error alert merah), tampilkan asset & checkout aktif; form return (datetime, penerima select, notes, signature). Kartu info asset/checkout; pending list card dengan CTA “Check In” cepat; tombol Refresh; toast notifikasi; warna netral/amber/emerald untuk status.
- **Stock Opname List (`src/app/so-asset/page.tsx`)** – Header kartu border-radius besar, CTA New Session (ADMIN). Kartu ringkasan Active/Completed dengan ikon Activity/ShieldCheck. Filter search + chips status. Kartu sesi: status pill warna, jadwal, target vs scanned, progress bar, completion notes, actions (start scan, view results, cancel/delete). Empty state dashed. Viewer mendapat banner read-only.
- **SO Scan Workspace (`src/app/so-asset/[id]/scan/page.tsx`)** – Layout dua kolom: kiri list assets (tabs Scanned/Pending/Remaining) dengan search, filter dropdown (status/kategori/site/dept), sort tiles; kanan catatan sesi + tindakan selesai/cancel/delete. Tile asset pakai badge status, waktu scan, lokasi/kategori; pending highlighted amber; remaining dashed border. AssetDetailModal bisa edit/mark crucial/pending; session notes textarea dengan save/reset; action dialog (complete needs notes). Progress header dengan KPIs. Banyak logging/debug di fetch; pakai `AssetScanPanel` untuk scanning.
- **SO Results (`src/app/so-asset/[id]/show-results/page.tsx`)** – Read-only report: header dengan back button, status badge, nama + year + description. KPI cards total/scanned/remaining/progress. Search bar. Tabs scanned/remaining; kartu asset dengan badge status, metadata; detail modal read-only. Empty state dashed.
- **Scan Placeholder (`src/app/scan/page.tsx`)** – “Coming Soon” hero dengan gradient blue-purple, icon rocket; dua kolom cards (new features/technical improvements) border dashed; CTA ke Stock Opname & Assets; status cards grid. Protected route tetap aktif.
- **Tools (`src/app/tools/page.tsx`)** – Grid cards dengan ikon berwarna; export assets CSV aktif (loader state). Backup dummy. Beberapa tool “coming soon” dengan badge kuning dan tombol disabled. Panel “system health” status hijau. Desain sederhana border abu.
- **Admin Assets (`src/app/admin/assets/page.tsx`)** – Metrik cards (total/active/total value). Toolbar search + filter status/kategori/site; aksi Import/Export/Add. Tabel aset dengan badge status + ikon, PIC/brand/model info; modals add/edit/delete/detail; import modal dengan hasil (imported/skipped/issues). Layout klasik putih/border, toast feedback.
- **Admin Users (`src/app/admin/users/page.tsx`)** – Header gradient, CTA Add User. Filters: search, role select, reset. List tabel + kartu mobile; badge role berwarna (Admin merah, SO blue, Viewer abu), badge status. Dialog create/edit/reset password/delete dengan input & switch status. Pagination footer. Hanya ADMIN via RoleBasedAccess.
- **Admin Categories/Sites/Departments (`src/app/admin/categories|sites|departments/page.tsx`)** – Kartu metrik total & total assets (kategori). Toolbar search + Add. Tabel dengan ikon Tag/Building/Users; modals add/edit/delete/detail; hitung aset terkait (kategori). Desain putih/border, hover row.
- **Admin Backup (`src/app/admin/backup/page.tsx`, `src/components/backup-manager-panel.tsx`)** – Hero safety card dengan gradient overlay; panel backup/import/clean: progress bar, status copy, toast; export backup ZIP (`/api/backup/export`), import ZIP (`/api/backup/import`) dengan preview tabel restored, clean sandbox (`/api/backup/clean`) dengan ringkasan tabel. Tip cards untuk backup/restore.
- **Auth Routing & Guard** – Root redirect: cookie `auth_token` → `/dashboard`, else `/login`; `/logout`; `/unauthorized` untuk akses ditolak. Hampir semua halaman pakai `ProtectedRoute`; role granular via `RoleBasedAccess` (ADMIN/SO_ASSET_USER/VIEWER) untuk aksi & akses.
